# pairwise-ray-denoise

光追反射一移动就拖尾、毛发边缘糊、暗部噪点像油画：降噪只用空间核；时间累积按帧数；法线/深度引导用单通道；反射光线长度不参与；高光被模糊；运动物体不重置历史；低分辨率反射直接上采样；多光源采样数固定；降噪在色调映射后；VR 双眼降噪不同步。render/raytrace_denoise.py 是核心，tests/test_raytrace_denoise.py 15个红。要修的是：空时联合；时间自适应；法线深度引导；光线长度权重；高光保护；运动重置；深度感知上采样；自适应采样；线性空间降噪；双眼独立。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
